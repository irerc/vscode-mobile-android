# VS Code Mobile 功能矩阵

对照桌面版 VS Code 1.144.0 的功能清单，逐项说明在 Android 单 APK 版本中的实现方式与状态。

状态图例：

- **可用** —— 与桌面版行为一致，已在容器内以同一份 serve-web 产物验证。
- **可用（触屏适配）** —— 功能完整，但交互按触屏习惯使用（长按代替右键、双指缩放代替 Ctrl+滚轮等）。
- **受限** —— 功能存在，但受 Android 平台或本移植架构限制，行为与桌面版有差异。
- **不适用** —— 依赖桌面专属能力（多窗口、系统托盘等），不属于本移植目标。

| 功能 | 状态 | 说明 |

| 语法高亮（内置语言） | 可用 | 94 个内置扩展随包发布 |
| 智能补全 / 参数提示 / 快速信息 | 可用 | 语言服务在扩展宿主进程内运行 |
| 转到定义 / 引用 / 符号 | 可用 | 同上 |
| 重命名符号 / 代码操作 / 格式化 | 可用 | 同上 |
| 查找替换（含正则、文件内与全局） | 可用 | |
| 多文件标签页、拆分编辑器 | 可用 | 单窗口内网格布局 |
| 命令面板（Ctrl+Shift+P） | 可用 | 触屏可通过菜单按钮打开 |
| 撤销 / 重做 / 剪贴板 | 可用 | 走 Android 剪贴板桥 |
| 缩略图、面包屑、括号配对、代码折叠 | 可用 | |

## 五、扩展

| 功能 | 状态 | 说明 |
|---|---|---|
| 扩展市场搜索 / 安装 / 卸载 | 可用 | 走 `open-vsx` 与微软市场，需网络 |

| 语言服务器（LSP） | 可用 | 纯 JS/TS 的直接可用；需原生二进制的要装 linux-arm64 版 |
| 调试适配器（DAP） | 可用 | 同上 |
| 主题 / 图标 / 键位扩展 | 可用 | |

| 需桌面 GUI 的扩展 | 不适用 | 例如依赖 Electron 主进程的扩展 |

## 七、账号与云服务

| 功能 | 状态 | 说明 |
|---|---|---|
| 设置同步 | 受限 | 需要微软账号，且服务端需能访问外网 |
| GitHub 账号登录 | 受限 | 同上，需自行完成 OAuth |
| Copilot | 受限 | 为控制体积已裁剪 `extensions/copilot` 与 `node_modules/@github`，可自行安装扩展 |
| Live Share | 不适用 | 依赖微软实时服务与额外原生组件 |
| 远程开发（SSH / 容器 / WSL） | 受限 | 可连出，但本机即目标环境，通常不需要 |

## 八、平台相关

| 功能 | 状态 | 说明 |
|---|---|---|
| 打开手机存储里的项目 | 受限 | 需通过应用私有目录或已授权目录，`Android/data` 不可读写 |
| 从系统文件管理器「用 VS Code 打开」 | 可用 | 已注册 VIEW intent |
| 后台保活 | 受限 | 由 Android 电池策略决定，见 `known-issues.md` |
| 离线启动 | 可用 | 全部运行时不依赖网络 |
| 多用户 / 多实例 | 不适用 | 单实例单服务端 |

## 九、验证方式

上表中标记为「可用」的项，其底层能力来自与桌面版完全相同的 `serve-web` 产物，已在容器内用 APK 自带的两份 tar.gz 解包后实测：

- 服务端 4 秒内监听成功，`GET /` 返回 200。
- 返回页面包含 `workbench` 入口，`workbench.js`、`workbench.css`、`nls.messages.js`、图标与 manifest 全部 200。
- 日志出现 `Extension host agent started.`，说明扩展宿主已就绪。

真机上与「触屏适配」「受限」相关的项需要在安装后按 `README.md` 第七节的清单逐条确认。
